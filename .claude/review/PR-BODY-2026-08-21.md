## What ships

**Library Share — the materials mini-site (Phase 1).** A share control immediately left of the
editor's "Extended" button mints one public link to a project's simulations, images, videos and
sounds, with typed sub-routes (`/library/simulation|images|videos|sounds`). It writes **zero bucket
objects** — one ~250-byte Postgres row per shared project, with every material URL re-emitted from
keys that already exist. The page is an ISR render at `revalidate = 60`, purged on revoke.

**Dubbing (ElevenLabs Dubbing v2) + a viewer language switcher.** Creators pick target languages in
project settings; viewers switch language from inside the player's existing caption-settings menu,
which navigates to the language-suffixed URL and reloads with that dub's audio **and its own
captions**. Captions for a dubbed language are derived from that dub's segments — never from an
independent Whisper translation, because two translations diverge and the viewer would read one
wording while hearing another.

**Crop v2 — measurement first, then the fixes that measurement justified.** An eval harness with
mIoU / subject-out-of-frame / jitter metrics, an algorithm version stamped into the idempotency hash
(so a fix can actually reach already-processed videos), and the P1 corrections:

| metric | v1 | after P1 |
|---|---|---|
| mIoU ↑ | 0.585 | **0.643** |
| subject out of frame ↓ | 0.363 | **0.331** |
| jitter ↓ | 0.0126 | **0.0081** |
| mIoU, dark skin ↑ | 0.272 | **0.508** |

## Three things a reviewer should push on

1. **The crop numbers are measured on synthetic fixtures, not catalogue footage.** They are honest
   and reproducible (`pnpm --filter backend-api eval:crop`), but they are not field results and the
   PR does not claim they are. The face detector (P2) is **not** in this release: YuNet returns zero
   detections against those fixtures, so it could not be scored, and the dependency and model were
   removed rather than landing ~1,000 unverifiable lines behind a flag nothing could validate.
2. **Nothing in the dubbing pipeline has met the live vendor API** — no key, no network in the build
   environment. `ELEVENLABS_DUBBING_WATERMARKED` therefore defaults to `true` and withholds every dub
   from viewers: the vendor exposes no watermark field on any v2 response, so it must be declared,
   and an unset variable has to fail toward "nobody sees a watermarked video". The ranked list of
   unverified call shapes is in the dubbing report §7.
3. **A discovery worth carrying forward: the active-speaker correlator performs below chance.** It is
   correct 17–46% of the time it fires, against 50% for guessing, and an 80-point threshold sweep
   found no configuration that beats a coin. Deleting the gender→region gap-fill alone regressed the
   end-to-end test, so the slot was *replaced* with shot-level speech-correlated motion rather than
   emptied. Future work here fixes a signal that carries no information; it does not tune a threshold.

## Also in this branch

- A per-user monthly dubbing ceiling, checked **before** the vendor is called — ElevenLabs bills on
  job creation and has no idempotency key, so a limit enforced afterwards is a report, not a limit.
  The route test asserts the vendor mock was never invoked on a refusal.
- Playback position now survives a language switch (`?t=`), consumed once on first play through the
  **existing** scrub path rather than a second implementation — so the in-flight-swap rule whose
  comment records wedging the player permanently guards the resume too.
- The share dialog names the video instead of saying "this project".
- The local-capture harness is versioned at `scripts/dev/local-capture/` with derived paths; it used
  to sit untracked at the repo root, which is what blocked a deploy in PR #43.
